# 청암대학교 간호학과 조(팀) 자동 편성기

학년·반별 명단으로 조(팀)를 무작위 편성하고 조장을 정하는 웹앱입니다. `index.html` 파일 하나로 동작하며, 설치나 서버가 필요 없습니다.

## 주요 기능

| 구분 | 기능 |
|---|---|
| 학급 | 학년(1~4)·반(A~F)·교과목·과제명 설정. 명단·이력을 학급별로 따로 저장 |
| 명단 | 엑셀/구글 시트 붙여넣기, CSV 불러오기(UTF-8·EUC-KR), 출석 체크로 결석자 제외, 표에서 바로 수정 |
| 조 구성 | 조당 인원 또는 조 개수 지정. 남는 인원은 "조 수 늘리기(인원 차 최대 1명)" 또는 "조 수 줄이기" |
| 조장 | 무작위 / 희망자 우선 / 순환(조장 경험 적은 학생 우선) / 학번 순 / 지정 안 함 |
| 균형 | 성별 균형, 특성(편입·재수강 등) 분산, 이전 조원 중복 피하기 |
| 고급 | 서로 다른 조에 배치할 학생, 특정 조에 고정할 학생, 편성 번호(시드)로 결과 재현 |
| 결과 | 클릭·끌어다 놓기로 자리 바꾸기, ☆로 조장 변경, 발표 모드(한 조씩 공개), 텍스트 복사, CSV 저장, 인쇄 |
| 이력 | 편성 결과 저장·불러오기·삭제, 조장 횟수 집계, JSON 백업·복원 |
| 연출 | 편성 시 이름 셔플 화면 → 조 카드 순차 등장 → 완료 배너·컨페티·팡파르. 발표 모드 공개음. 화면을 누르면 건너뛰기, 우측 상단에서 소리 켜기/끄기 (효과음은 Web Audio로 합성, 외부 파일 없음. 시스템의 ‘동작 줄이기’ 설정 시 애니메이션 생략) |

## 사용 방법

1. `index.html`을 브라우저로 엽니다. GitHub Pages로 배포하면 링크로 쓸 수 있습니다.
2. 학년·반을 고르고 명단을 붙여넣은 뒤 **명단에 추가**를 누릅니다.
   ```
   학번	이름	성별	특성	조장희망
   20260101	김민지	여	편입	O
   20260102	이현우	남
   ```
   - 시험용 가상 명단: `sample_roster_38.csv`(38명, 가상 인물)를 **CSV 파일 불러오기**로 열 수 있습니다.
3. 편성 옵션을 정하고 **조 편성하기**를 누릅니다.
4. 확정한 결과는 **이력에 저장**합니다. 저장된 이력은 다음 편성 때 중복 회피와 조장 순환에 쓰입니다.

## GitHub Pages 자동 배포

이 저장소는 GitHub Pages가 **Deploy from a branch (`index` / root)** 로 설정되어 있어, `index` 브랜치에 푸시하면 1~2분 안에 자동으로 다시 배포됩니다.

- 배포 주소: https://jp5678.github.io/Group-Formation/
- 배포 상태 확인: 저장소 **Actions → pages build and deployment**

## 개인정보

명단과 이력은 브라우저의 localStorage에만 저장되며 외부로 전송되지 않습니다. 다른 PC로 옮길 때는 **전체 데이터 백업**으로 만든 JSON 파일을 **백업 복원**으로 불러옵니다. 공용 PC에서는 사용 후 **이 반 데이터 삭제**를 권장합니다.

## 무작위 방식

- `crypto.getRandomValues()`로 6자리 편성 번호(시드)를 만들고, 그 번호를 시드로 쓰는 의사난수 생성기(sfc32)와 Fisher–Yates 셔플로 섞습니다.
- 균형 조건이 있으면 인원이 적은 집단(예: 남학생)부터 각 조에 고르게 배치합니다.
- 분리 조건이나 편성 이력이 있으면 여러 번(최대 400회) 시도해 위반·중복이 가장 적은 결과를 고릅니다.
- 같은 편성 번호·명단·옵션·이력이면 항상 같은 결과가 나옵니다.
