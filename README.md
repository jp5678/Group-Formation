# 팀 스테이션

> 청암대학교 간호학과 · 함께 공부할 동료를 만나는 곳

이름은 간호사들이 모여 업무를 나누는 **널스 스테이션(Nurse Station)**에서 따왔습니다.

학년·반별 명단으로 조(팀)를 무작위 편성하고 조장을 정하는 웹앱입니다. `index.html` 파일 하나로 동작하며, 설치·회원가입·서버가 필요 없습니다. PC와 휴대폰 브라우저에서 모두 쓸 수 있습니다.

- 바로 쓰기: **https://jp5678.github.io/Group-Formation/**

## 화면 구성

화면은 위에서 아래로 단계별 카드로 나뉩니다. 카드마다 **번호 원·아이콘·왼쪽 색 막대**가 같은 색이라 색과 모양 모두로 단계를 구분할 수 있습니다.

| 단계 | 카드 | 색 | 하는 일 |
|---|---|---|---|
| 1 | 반·과제 정보 | 학년별 색 (1학년 하늘 · 2학년 청록 · 3학년 남보라 · 4학년 장미) | 학년·반 선택, 교과목명·과제명 입력 |
| 2 | 학생 명단 | 초록 | 명단 붙여넣기·불러오기, 출석 체크, 표에서 수정 |
| 3 | 편성 옵션 | 주황 | 조 구성 방식, 조장 선정, 균형 조건, 고급 조건 |
| 4 | 편성 결과 | 파랑 | 결과 확인·조정, 발표 모드, 복사·CSV·인쇄, 이력 저장 (편성 후에만 표시) |
| 4/5 | 편성 이력 | 보라 | 저장한 결과 불러오기·삭제 (결과 카드가 없을 때는 4번, 있을 때는 5번) |

- **오른쪽 위 버튼**: 🔊 소리 켜기/끄기(청록), ☀/🌙 라이트·다크 모드 전환(보라). 테마는 처음에는 기기 설정을 따르고, 한 번 고르면 그 선택을 기억합니다.
- **아이콘**: 제목 앞의 하트·십자 간호 상징 아이콘을 브라우저 탭 아이콘(파비콘)으로도 씁니다.
- **현재 반 표시줄**: 아래로 내려 '반·과제 정보' 카드가 화면에서 사라지면 상단에 `3학년 B반 · 과목 · 과제` 표시줄과 **[변경] [조 편성하기]** 버튼이 나타납니다.

## 사용 도우미 (FAQ 챗봇)

화면 오른쪽 아래 **말풍선 버튼**을 누르면 '팀 스테이션 도우미'가 열립니다.

- 자주 묻는 질문 버튼을 누르거나 질문을 직접 적으면, 미리 준비한 **약 27개 답변** 중 가장 알맞은 것을 보여줍니다. 답변 아래 버튼으로 해당 화면에 바로 이동할 수 있습니다.
- **사용법 안내 전용**입니다. 수업 내용·과제 답안·잡담·부적절한 말 등 범위 밖 질문은 정중히 거절하고 교수님께 문의하도록 안내합니다.
- AI가 아닌 **핵심어 규칙**으로 답합니다. 질문은 기기 밖으로 전송되지 않으며 비용도 없습니다. 대신 표현이 많이 다르면 알아듣지 못할 수 있으니, 짧고 구체적으로 물어보세요(예: "결석한 학생은 어떻게 빼요?").
- Esc로 닫습니다. 인쇄할 때는 표시되지 않습니다.

## 사용 방법

1. **반·과제 정보**: 학년·반을 고르고 교과목명·과제명을 입력하거나 ▼ 목록에서 고릅니다.
2. **학생 명단**: 엑셀/구글 시트에서 복사해 붙여넣고 **명단에 추가**(기존 명단에 더하기) 또는 **명단 바꾸기**(새로 교체)를 누릅니다.
   ```
   학번	이름	성별	특성	조장희망
   20260101	김민지	여	편입	O
   20260102	이현우	남
   ```
   - 첫 줄에 제목 행이 있으면 열 이름으로 자동 인식합니다. 이름만 한 줄씩 넣어도 됩니다.
   - 연습용 명단: **예시 명단 넣기**(43명) 또는 `sample_roster_38.csv`(38명)를 **CSV 파일 불러오기**로 엽니다. 모두 가상 인물입니다.
   - 결석한 학생은 표의 출석 체크를 풀면 이번 편성에서 빠집니다.
3. **편성 옵션**: 조당 인원(또는 조 개수), 조장 선정 방식, 균형 조건을 정합니다. 아래 미리보기에 `출석 38명 → 8개 조 (5명 × 6개, 4명 × 2개)`처럼 결과 규모가 표시됩니다.
4. **조 편성하기**를 누르면 룰렛이 돌고 결과가 나옵니다. 마음에 들지 않으면 **다시 섞기**를 누릅니다.
5. 필요하면 결과에서 자리·조장을 조정하고, **발표 모드**로 한 조씩 공개합니다.
6. 확정한 결과는 반드시 **이력에 저장**합니다. 저장된 이력은 다음 편성 때 '이전 조원 중복 피하기'와 '조장 순환'에 쓰입니다.

무엇을 누르면 무엇이 지워지는지 정리했습니다. **지운 데이터는 되돌릴 수 없으니** 중요한 자료는 미리 백업하세요.

| 버튼 | 명단 | 화면의 편성 결과 | 저장된 편성 이력 |
|---|---|---|---|

| 백업 복원 | 백업 내용으로 교체 | 닫힘 | 백업 내용으로 교체 |

## 인쇄·내보내기

- **인쇄**: 결과 카드만 **컬러**로 출력합니다(조별 색 카드, 조장 강조, 성별 배지). 화면이 다크 모드여도 인쇄는 밝은 색으로 나오며, 브라우저의 '배경 그래픽' 옵션을 따로 켜지 않아도 됩니다. 흑백 프린터에서는 연한 회색 음영으로 나옵니다.
- **CSV 저장**: 조·조 이름·역할·학번·이름·성별·특성을 엑셀에서 열 수 있는 형식으로 저장합니다. `=`, `+`, `-`, `@`로 시작하는 값은 엑셀이 수식으로 실행하지 않도록 앞에 `'`를 붙입니다.
- **텍스트 복사**: 단톡방·LMS 공지에 붙여넣기 좋은 형식으로 복사합니다.

## GitHub Pages 자동 배포

이 저장소는 GitHub Pages가 **Deploy from a branch (`index` / root)** 로 설정되어 있어, `index` 브랜치에 푸시하면 1~2분 안에 자동으로 다시 배포됩니다.

- 배포 주소: https://jp5678.github.io/Group-Formation/
- 배포 상태 확인: 저장소 **Actions → pages build and deployment**
- 배포 직후에는 브라우저가 이전 버전을 보여줄 수 있습니다(GitHub Pages 캐시 최대 10분). **Ctrl+Shift+R**(Mac은 Cmd+Shift+R)로 강력 새로고침하세요.

### 새 버전 알림

- 화면 맨 아래에 현재 **버전**(예: `버전 2026.11.05-r2`)이 표시됩니다.
- 앱을 열어 둔 상태에서 새 버전이 배포되면 화면 왼쪽 아래에 **‘새 버전이 있습니다’** 안내와 **[새로고침] [나중에]** 버튼이 뜹니다. ‘나중에’를 누르면 30분 뒤 다시 알려 줍니다.
- 확인 시점: 페이지를 연 지 3초 뒤, 이후 5분마다, 다른 탭에 갔다가 돌아올 때. 같은 사이트의 `index.html`만 다시 받아 비교하며 학생 데이터는 보내지 않습니다.
- 저장하지 않은 편성 결과가 있으면 “새로고침하면 사라진다”고 경고합니다. 명단·이력은 브라우저에 저장되어 있어 새로고침해도 남습니다.
- **배포할 때 버전 올리기**: `index.html` 위쪽의 `<meta name="app-version" content="…">` 값을 바꿔 주세요. 깜빡하더라도 페이지 내용이 바뀌면 안내가 뜨지만, 버전을 올려야 맨 아래 표시와 캐시 상황에서도 정확히 알 수 있습니다.

## 개인정보

- 명단과 이력은 브라우저의 localStorage에만 저장되며 **외부로 전송되지 않습니다.** 따라서 다른 PC나 다른 브라우저에는 보이지 않습니다.
- 다른 PC로 옮길 때는 **전체 데이터 백업**으로 만든 JSON 파일을 **백업 복원**으로 불러옵니다. 테마·소리 설정과 추천 목록도 함께 복원됩니다.
- 학번·이름은 개인정보입니다. 공용 PC에서는 사용 후 **이 반 데이터 삭제**를 권장합니다.

## 무작위 방식

- `crypto.getRandomValues()`로 6자리 편성 번호(시드)를 만들고, 그 번호를 시드로 쓰는 의사난수 생성기(sfc32)와 Fisher–Yates 셔플로 섞습니다.
- 균형 조건이 있으면 인원이 적은 집단(예: 남학생)부터 각 조에 고르게 배치합니다.
- 분리 조건이나 편성 이력이 있으면 여러 번(최대 400회) 시도해 위반·중복이 가장 적은 결과를 고릅니다.
- 같은 편성 번호·명단·옵션·이력이면 항상 같은 결과가 나옵니다.
- **룰렛은 연출일 뿐입니다.** 조 편성은 룰렛이 돌기 전에 이미 계산되며, 룰렛이 멈춘 이름은 결과와 관계가 없습니다.

## 자주 묻는 질문

**Q. 고친 내용이 화면에 안 보여요.**
배포 후 브라우저 캐시 때문입니다. 화면 왼쪽 아래의 ‘새 버전이 있습니다’ 안내에서 **새로고침**을 누르거나, Ctrl+Shift+R로 강력 새로고침하세요. 화면 맨 아래 버전 번호로 최신인지 확인할 수 있습니다.

**Q. 다른 컴퓨터에서 열었더니 명단이 없어요.**
데이터는 브라우저마다 따로 저장됩니다. 원래 PC에서 **전체 데이터 백업** → 새 PC에서 **백업 복원**을 하세요.

**Q. 이전 조원과 또 같은 조가 됐어요.**
'이전 조원 중복 피하기'는 **이력에 저장한** 편성만 참고합니다. 편성 후 꼭 **이력에 저장**하세요. 인원과 조 수에 따라 완전히 피할 수 없을 때는 겹침이 가장 적은 결과를 고릅니다(결과 화면에 '이전 조원 재회 n쌍'으로 표시).

**Q. 교과목명 목록에서 잘못 입력한 값을 지우고 싶어요.**
